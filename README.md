# University-of-Manchester-Bioinformatics-Research-Project-2-supplementary-material-
University of Manchester, Bioinformatics Research Project 2 supplementary material _ Jacob Tudor, Dr Michael Buckley, Dr Alexander Eckersley

This repository contains the supplementary material for Bioinformatics Research Project 2 supplementary material conducted by student Jacob Tudor and supervised by Dr Michael Buckley, Dr Alexander Eckersley.  

Contents: 
Methods, Results and Discussion: .docx contains the Analysis of PTMs across PLF identified regions of age-associated structural difference. Methods, Results and limitations included. Description of custom built scripts provided. Document of mapped PTMs also provided

PTM_Graphs: 
This directory contains a list of subdirectories each containing the results of PTM quantification across all peptides identified by Mascot MS/MS ion search to belong to that protein. Visualisations show for each region displaying significant differences in average peptide spectral count as explained in the main paper; the of Average total PTM abundance across statistically significant regions of age associated structural change +- 50aa. PTMs quantified include Oxidation of Methionine, Lysine and Proline, Deamidation of Asparagine and Glutamine and, galactosyl and glucosylgalactosyl glycosylations of Lysine. For each PTM overlapping bars are displayed, the lighter bar representing the Average total PTM abundance across the significant 50aa region +- 50aa. The darker region displays the Average total PTM abundance within the signiificant 50aa region. 
- note: The average number of PTMs is the average number found across all peptides mapped to that location along the specified protein. This is why you can have more modifications identified than there are valid aminio acids within the target sequence. 

.csv files: PTMs in male and female specimens across juvenile and adult rats in regions identified by PLF to express age-associated differences in protein structure and the surrounding adjacent 50aa regions. 

Jupyter notebooks: Files used to build the tools and visualisations used to generate and analyse the data
